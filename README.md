# Do'stlik Burger: Business Calculator

A sales and expense tracker built for a local burger business. It records daily sales and purchases and calculates profit automatically.

**Live demo:** https://do-stlik-burger.vercel.app

## Features

- **Sales entry**: record products sold and quantities
- **Purchases / expenses entry**: track ingredient purchases and other costs
- **Automatic profit calculation**: daily and monthly
- **Last 7 days chart** of sales and profit
- **Top products of the month**
- Sales and purchase history
- Data is saved in the browser with `localStorage`, so nothing is lost on refresh

## Tech stack

- React 19
- Vite
- CSS
- localStorage
- Deployed on Vercel

## Getting started

The app lives in the `dostlik-burger` folder:

```bash
git clone https://github.com/zoxirshoh/dostlik-burger.git
cd dostlik-burger/dostlik-burger
npm install
npm run dev
```
